# CLAUDE.md — CatsUp

## Overview
AI-powered meeting assistant that runs locally. Detects when you join a meeting (Teams, Zoom, Slack, Google Meet), records the session, transcribes in real-time, and generates AI summaries. Cross-platform (Windows, macOS, Linux).

## Tech Stack
- TypeScript (core logic)
- Electron or native platform shells (macOS menu bar, Windows system tray, Linux)
- AI backends: OpenAI, Anthropic, Google, Ollama/llama.cpp (local)
- OCR + vision models for screen understanding

## Development
Build instructions vary by platform. Check `platform/` for OS-specific build steps.

```bash
# macOS (Homebrew)
brew tap geiserx/catsup
brew install --cask catsup
```

Or download from the [Releases page](https://github.com/GeiserX/CatsUp/releases).

## Architecture
- `core/` — platform-agnostic business logic
  - `ai/` — AI provider integrations
  - `capture/` — audio/video recording
  - `detect/` — meeting detection
  - `events/` — event system
  - `integrations/` — external service connectors
  - `policy/` — privacy and recording policies
  - `storage/` — transcript and recording storage
  - `vision/` — screen OCR and vision AI
- `platform/` — OS-specific implementations (linux, macos, windows)
- `ui/` — user interface components
- `ai-backends/` — AI model configurations
- `shared/` — shared utilities
- `tests/` — test suite

## Key Rules
- Never hardcode API keys; users configure them in Settings
- Support both cloud and fully-local (Ollama) processing modes
- Stealth mode is a core requirement — app must be unobtrusive
